# Local Gym Website 💪

**Responsive Local Gym Website** built with **HTML, CSS, and JavaScript**, designed to showcase gym facilities, trainer profiles, classes, and membership plans.

---

## 🚀 Features

- Modern and **responsive design** for desktops, tablets, and mobiles.  
- **Trainer profiles** with images and specialization.  
- **Class schedules** and membership packages.  
- Interactive buttons and smooth **hover effects**.  
- Clean UI with **modern color scheme** to enhance user experience.

---

## 🛠️ Technologies Used

- **HTML5** for semantic structure  
- **CSS3** for modern styling and responsiveness  
- **JavaScript** for interactivity and animations
